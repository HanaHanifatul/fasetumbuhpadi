Pendahuluan

Latar Belakang

Indonesia menempati posisi keempat konsumsi beras tertinggi dunia (36,6 juta ton/tahun), sementara produksi padi nasional terus menurun dari 59,20 juta ton (2018) menjadi 53,14 juta ton (2024). Kabupaten Karawang, sebagai sentra padi kedua terbesar Jawa Barat dengan produksi ±1,04 juta ton menjadi wilayah strategis untuk pemantauan.

  • Metode KSA konvensional mahal & tidak real-time.
  • Sensor tunggal tidak mampu merepresentasikan semua kondisi lahan.
  • Model nontemporal rentan misklasifikasi fase serupa.

Rumusan Masalah

  • Kesenjangan arsitektur: Model LSTM satu arah (Thorp & Drajat, 2021) tidak memanfaatkan konteks temporal dari dua arah, menyebabkan misklasifikasi pada fase transisi seperti vegetatif akhir ke generatif.
  • Keterbatasan data: Sentinel-1 rentan speckle noise; Sentinel-2 rentan tutupan awan tropis. Evaluasi kontribusi tiap sensor diperlukan.
  • Ketiadaan peta piksel: Survei KSA belum menghasilkan peta sebaran fase tumbuh padi hingga tingkat piksel.

Tujuan Penelitian

  1. Membangun dan mengevaluasi arsitektur Bidirectional Long Short-Term Memory (Bi-LSTM) untuk klasifikasi fase tumbuh padi menggunakan data fusi Sentinel-1 dan Sentinel-2, serta membandingkan kinerjanya dengan arsitektur Long Short-Term Memory (LSTM) pada penelitian Thorp dan Drajat (2021).
  2. Menganalisis kontribusi relatif fitur Sentinel-1 dan Sentinel-2 terhadap akurasi klasifikasi fase tumbuh padi melalui eksperimen sembilan skenario fitur menggunakan model Bi-LSTM.
  3. Menghasilkan peta spasial fase tumbuh padi di Kabupaten Karawang pada periode Juli–Desember 2025 menggunakan model terbaik.

Pendahuluan

Mengapa Fase Tumbuh Padi Penting?

Padi merupakan salah satu komoditas pangan utama ketiga di dunia. Setiap fase pertumbuhannya memiliki karakteristik dan kebutuhan yang berbeda sehingga informasi mengenai fase tumbuh dapat membantu memahami kondisi pertanaman serta mendukung pemantauan area panen dan produksi padi.

Masalah dan Keterbatasan

Keterbatasan KSA

KSA menyediakan informasi fase tumbuh berdasarkan survei lapangan, tetapi belum menghasilkan gambaran sebaran fase tumbuh secara kontinu hingga tingkat piksel.

Keterbatasan Sensor

Sentinel-1 dapat dipengaruhi speckle noise, sedangkan Sentinel-2 menghadapi tutupan awan. Penggunaan kedua sumber data dapat memberikan informasi yang lebih beragam.

Pola Pertumbuhan Bersifat Temporal

Karakteristik fase tumbuh dapat memiliki kemiripan pada satu waktu. Karena itu, informasi perubahan kondisi pertanaman dari waktu ke waktu penting dalam proses klasifikasi.

Tujuan Penelitian

01

Mengembangkan Model Bi-LSTM

Membangun dan mengevaluasi model Bidirectional Long Short-Term Memory (Bi-LSTM) menggunakan fusi data Sentinel-1 dan Sentinel-2 untuk mengklasifikasikan fase tumbuh padi, serta membandingkan kinerjanya dengan model LSTM penelitian Thorp dan Drajat (2021).

02

Menganalisis Kontribusi Fitur

Menganalisis kontribusi relatif fitur Sentinel-1 dan Sentinel-2 terhadap klasifikasi fase tumbuh padi melalui sembilan skenario kombinasi fitur menggunakan model Bi-LSTM.

03

Menghasilkan Peta Fase Tumbuh

Menghasilkan peta spasial fase tumbuh padi di Kabupaten Karawang untuk periode Juli–Desember 2025 menggunakan model dengan kinerja terbaik.
